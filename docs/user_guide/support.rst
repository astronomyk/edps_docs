Questions and feedback
======================

For suggestions, questions, or feedback in general, please open a ticket with
the **EDPS Support team**.

`Submit an EDPS ticket <https://support.eso.org>`_

That link should take you directly to a webpage for creating an EDPS feedback
ticket. In case you want to navigate there manually, go to
https://support.eso.org, log in, click on "Submit Helpdesk Ticket", and specify
the Help topic: *"Post Observations"*, *"ESO Data Processing System [EDPS]"*.

.. note::

   Questions about EDPS itself — bugs, unexpected reduction results, missing
   workflows, pipeline behaviour — should go to ESO via the link above.

   Problems with *this documentation site* (a broken link, a typo, a page that
   contradicts the software) belong in the site's own issue tracker instead;
   see :doc:`../about`.
