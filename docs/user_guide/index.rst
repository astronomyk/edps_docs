User Guide
==========

This guide describes how to reduce data with EDPS. It is aimed at first-time
users: it covers installation, then a complete data reduction using the
ESPRESSO pipeline and its demo data as the worked example. After working
through it you should be able to use any supported EDPS workflow on your own
data.

Where a feature is not available in the ESPRESSO workflow, an example from
another instrument (KMOS, MUSE, UVES) is used instead.
