# edps_docs

Unofficial Sphinx/Read the Docs rendering of ESO's **EDPS** (ESO Data Processing
System) manuals.

ESO distributes the EDPS documentation as PDF only. This repo converts that
material into a searchable, linkable, version-controlled HTML site.

## What's here

| Section | Source |
| --- | --- |
| User Guide | *EDPS Tutorial* v0.9.7 (2024-12-20) |
| Workflow Developer Guide | *EDPS workflow design tutorial* v0.8 (2023-12-01, draft) |
| Worked examples | Part IV of the workflow design tutorial |
| Reference | Generated by introspecting an EDPS **1.7.1** install |

The reference section is not a transcription — it documents the CLI, the full
`application.properties` file, the builder API, validity ranges and metatargets
as they actually exist in EDPS 1.7.1. The manuals were written against 1.3.3 and
have drifted; discrepancies are flagged inline throughout the site.

Original text is by L. Coccato, W. Freudling and S. Zampieri (ESO, Science Data
Quality Group). Copyright in that material remains with ESO.

## Building locally

```bash
python -m venv .venv && . .venv/bin/activate
pip install -r docs/requirements.txt
python -m sphinx -b html docs _build/html
```

Then open `_build/html/index.html`.

## Publishing

`.readthedocs.yaml` at the repo root configures the Read the Docs build
(Ubuntu 22.04, Python 3.12, HTML + PDF + htmlzip). Import the repo at
readthedocs.org and it should build without further configuration.

## Contributing

Corrections to this rendering — typos, broken links, pages that contradict the

<https://support.eso.org> → "Submit Helpdesk Ticket" → "Post Observations" →
"ESO Data Processing System [EDPS]".
